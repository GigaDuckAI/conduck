### [P1] MAC-R1-P1-D partially fixed: the quit guard still permits termination without durable capture bytes

- **Failure scenario** — Stop Work and quit while compression, screenshot import or recording publication takes longer than five seconds. Propagate screenshot-write failure into that accounting. Test timeout, failed preservation and simultaneous recorder instances. The protection is **not genuinely pinned**: changing the wait condition from `> 0` to `> 1` satisfies the existing guards and count measurements while skipping protection for one capture. The measurement itself is macOS-only and absent from the prescribed iOS test execution.
